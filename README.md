# copilot-web-browser

A glassmorphism-style web browser app with:

- Tabs
- Bookmarks
- Profiles
- Settings (theme + animation controls)
- Extensions panel (toggleable demo extensions)
- Built-in video and audio player

## Run locally

Open `/home/runner/work/copilot-web-browser/copilot-web-browser/index.html` in a browser.

## Deploy to Vercel

This repository includes `vercel.json` for static hosting.

1. Import the repository in Vercel.
2. Keep framework preset as **Other**.
3. Deploy.
